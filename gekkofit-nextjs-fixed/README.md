# GEKKO FIT

Готовый frontend-прототип трекера тренировок на Next.js + React + Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

## Что уже реализовано

- Главный экран «Тренировки»
- Поиск и фильтрация упражнений по группам мышц
- Карточки упражнений с рабочим весом и выносливостью
- Экран конкретного упражнения
- Добавление подходов: вес × повторения
- Автоматический расчёт XP по заданным коэффициентам
- Streak-множитель
- История подходов в рамках текущей сессии
- График 1RM и блок личных рекордов
- Система рангов: Бронза → Серебро → Золото → Платина → Алмаз → Обсидиан
- Профиль
- PWA manifest
- Переданный логотип GEKKO FIT в `public/gekkofit-logo.png`

## Важно

Это frontend-основа. Авторизацию, БД, синхронизацию между устройствами, реальные аккаунты и серверное хранение тренировок нужно подключить отдельно.
