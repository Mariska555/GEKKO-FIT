# GEKKO FIT 🦎

Трекер тренировок с системой XP, рангами и streak-множителем.
Next.js 14 (App Router) + Tailwind CSS, PWA-ready (манифест + service worker).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшн / установка на телефон как PWA:

```bash
npm run build && npm start
```

## Что внутри

- **Главный экран «Тренировки»** — шапка с рангом, XP и streak, поиск, фильтры по группам мышц, сетка упражнений с рабочим весом и прогресс-баром выносливости.
- **Экран упражнения** — форма подхода с живым расчётом XP, вкладки «История» и «Статистика» (график 1RM, тоннаж по дням, рекорды, динамика XP).
- **XP = вес × повторения × K(интенсивность) × K(streak)**
  - 1–5 повт. → K = 1.3 (сила), 6–12 → K = 1.0 (гипертрофия), 13+ → K = 0.8 (выносливость)
  - streak: 1 нед. → ×1.0, 2 → ×1.1, 3 → ×1.2, 4+ → ×1.5
- **Собственный вес**: подтягивания/отжимания/брусья считаются от 70% массы тела (+ доп. вес).
- **Ранги**: Бронза 0–2.5k · Серебро 2.5–10k · Золото 10–30k · Платина 30–75k · Алмаз 75–150k · Обсидиан 150k+ XP.
- Данные хранятся в localStorage (offline-first), бэкенд легко прикрутить позже.
